## Design Context

### Users

Developer-professionals who want automated AI pair programming with cross-validation. They're concerned about AI hallucinations and want confidence in generated code. Context: working on serious projects, want to delegate routine coding while maintaining oversight. Job to be done: run two AI agents that check each other's work so they can focus on review rather than constant intervention.

### Brand Personality

**Precision • Thoughtfulness • Modern**

The brand evokes confidence and trust in AI-generated code. Not playful or experimental—serious tooling for serious work. Refined aesthetic with glass/metal effects signals premium, polished experience. Voice is clear, direct, technical without being cold.

### Aesthetic Direction

**Refined glassmorphism** with metal sheen accents. Subtle gradients, blur effects, grain overlay for texture. Light mode is airy with blue-purple radial accents; dark mode is sophisticated with subtle glow effects. Typography: Geist Sans (display), Geist Mono (code/data). Status colors: blue (mentoring), purple (executing), amber (paused/reviewing), green (finished/ready).

**References**: Linear, Arc browser—premium tooling aesthetic
**Anti-references**: Generic SaaS gradients, cartoonish icons, heavy shadows

### Design Principles

1. **Trust through transparency** — Show agent activity, resource usage, git changes visibly so users understand what's happening
2. **Subtle sophistication** — Glass effects and metal accents feel premium without being flashy; animations are smooth, not bouncy
3. **Information density with clarity** — Compact cards pack data but remain readable through hierarchy, truncation, and consistent spacing
4. **Status-driven visuals** — Color coding (blue/purple/amber/green) makes pair state instantly scannable
5. **Responsive refinement** — Works beautifully from single column mobile to three-column desktop; spacing scales appropriately
